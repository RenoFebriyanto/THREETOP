Add payment method logos to this folder using the Duitku payment method code as
the lowercase filename:

- `m2.png` for method code `M2`
- `ov.png` for method code `OV`
- `vc.png` for method code `VC`

The code is provided by Duitku for each payment method and is visible in the
website's payment method list/API response. Use PNG images with transparent
backgrounds, preferably around 128x80 pixels. Until a logo is added, the
website shows a category fallback icon.
